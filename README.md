### ✨ Projetos em Destaque

Dá uma olhada em alguns dos projetos que mais curti desenvolver:

*   **[Brasfal](https://github.com/GuiRibeiro52/Brasfal)** - Um site institucional desenvolvido com React e Tailwind CSS, apresentando a empresa Brasfal.
*   **[Portfólio Sidebar](https://github.com/GuiRibeiro52/portifolio-sidebar)** - Um portfólio moderno e responsivo com navegação em barra lateral, construído com React, Vite e Tailwind CSS. Inclui suporte multilíngue e animações.
*   **[HBO Max Clone](https://github.com/GuiRibeiro52/hbo-max-clone)** - Um clone da interface do HBO Max, desenvolvido com React, TypeScript e Vite, demonstrando habilidades em construção de UI complexas e responsivas.
*   **[Spotify Clone](https://github.com/GuiRibeiro52/spotify-clone)** - Uma aplicação clone do Spotify, utilizando React, TypeScript e Vite, com autenticação via API do Spotify para visualizar playlists e artistas.
*   **[Furniro](https://github.com/GuiRibeiro52/Furniro)** - Uma aplicação de e-commerce de móveis online, desenvolvida com React, TypeScript e Vite. Utiliza Firebase para autenticação e ViaCep para busca de CEP.
*   **[Forever Homes](https://github.com/GuiRibeiro52/Forever-Homes)** - Uma aplicação web para ajudar no resgate e adoção de animais, desenvolvida com HTML, CSS e JavaScript. Inclui funcionalidades de adoção, doação e newsletter.
